# Major per Windows

Sorgenti desktop, test e dipendenze documentate. Per compilazione e download vedere il [README principale](../README.md).

Le dipendenze binarie e i sorgenti upstream di grandi dimensioni si ripristinano con `scripts/Restore-ReleaseDependencies.ps1`; sono inclusi integralmente nel pacchetto Windows della release. La companion Android è distribuita soltanto come APK nella cartella `../Android`.
